# Runtime 参数开发计划

1. 将默认模板、独立编辑草稿、冻结实验快照分开，默认配置只初始化一次，缺省从空对象开始。
2. 通用编辑器统一提供嵌套对象、数组、null、子字段及 JSON 导入导出，不读取 flat/nested 或执行 Schema 限制草稿。
3. 平台只校验通用 JSON，完整保存并原样下发，不补默认、不改名、不拆层；旧快照保留，契约确认使用原值。
4. 客户端保留 Schema、CLI/文件交付绑定，进程启动前检查最终值；上报描述只携带通用默认配置，MCTS 和 OpenCode 使用同一平台协议。
5. 验证模板与草稿隔离、默认值更新、空对象和删除语义、跨目标草稿、嵌套导入、创建/详情/复用/下发、客户端拒绝不支持的配置时快照不变。
6. 同步用户与开发者指南，运行专项回归、npm run test、相关 lint 和类型检查。按用户此前选择暂不启动 dev，未在浏览器中验证。
