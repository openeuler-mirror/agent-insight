# Runtime 参数配置需求

平台提供统一的嵌套 JSON 编辑、导入导出、个人模板、完整快照及原样下发能力，不按 Agent 名称或默认值的形状限制编辑、保存和提交。

客户端默认配置只用于初始化本次草稿：有默认值则复制，没有则从 `{}` 开始。编辑草稿不修改客户端模板，默认值更新不覆盖已有草稿；恢复默认需用户显式操作。对象、数组、null 与新增字段对所有 v2 Runtime 一致开放，不再使用 flat/nested 声明。

平台只做 JSON 通用校验，保留 Key、类型、层级、空对象和删除语义。MCTS 初始模板恰好平铺，用户仍可主动添加嵌套字段。实际参数支持情况、Schema 和 CLI/文件入口由客户端在进程启动前检查，不自动重组不支持的配置。

历史实验快照保持原样。契约变化时确认原始完整配置用于新草稿，不推断 MCTS 或其他应用的别名映射。客户端上报通用默认值，交付规则和业务 Schema 留在执行端。

不修改 Prisma，不新增 API 路由。已有参数协议、用户设置和实验 JSON 快照承载这些数据。旧逐字段协议保留兼容，通用配置要求新版客户端。
