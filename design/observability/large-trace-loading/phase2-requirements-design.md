# 原界面增量读取设计

原 TracePageContent、AgentTraceView 和所有现有工具栏保持；移除简化界面作为默认入口。Trace 列表沿用页码与每页数量，在后端分页后返回。统计单独聚合。详情结构固定每批 500 Span；滚动到已有内容底部再追加，保持选择、展开与滚动位置。以稳定 ID 去重，切换 Trace 取消请求。正文按 Span ID 读取。游标绑定 Trace 版本与顺序；更新时明确刷新，不能混入不同版本。排序保持调用时间及稳定 ID，并保留父节点关系。搜索、筛选应覆盖全部 Span；不得静默仅对部分数据计算。

验收包括原布局截图、首屏仅一批、连续滚动追加、全部 21,001 条唯一性、失败重试和权限隔离。Core 与原数据库分别明确支持状态。
