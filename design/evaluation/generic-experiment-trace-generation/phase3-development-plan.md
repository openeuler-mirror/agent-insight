# 通用实验 Trace 生成：开发计划

1. 扩展 `ExperimentCase`，保存普通 Trace 生成指令和失败信息。
2. 新增 `ExperimentTraceAttempt`，记录每次普通 Trace 生成尝试、Trace ID 与结构化失败。
3. 扩展客户端能力和命令结果契约，从平台结构化输出取得 Trace ID。
4. 修改通用 Trace 编排模块，移除输入匹配，改为 Trace ID 精确绑定并加入自动重试。
5. 新增 Case 级统一重试 API，Trace 失败时重新生成，评估失败时复用单项重评。
6. 修改实验详情聚合与操作列，展示 Attempt 状态并复用统一“重试”按钮。
7. 更新用户指南和开发者的数据流/API 契约说明。
8. 仅运行实验向导、实验 API、通用生成编排、客户端契约及执行目标相关的定向测试。
