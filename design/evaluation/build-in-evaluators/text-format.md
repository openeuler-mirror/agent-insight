# 文本格式规范性评估器

## 目标与输入

检查 Agent 最终输出的结构、标记和排版是否一致、可读且可渲染。仅评价 `actualOutput`，不把用户问题计入格式评分。

## 判定与输出

Judge 对七个固定维度返回 `safe/minor/moderate/severe`、问题原文、中文理由、修正建议和不超过 80 字的具体总结。没有列表、引用、表格或特殊格式时，对应维度必须判 `safe`。

模型调用固定使用 `temperature=0`，减少同一文本重复判档时的采样漂移；最终分仍完全由代码按离散等级确定。

输出包含 `score`、`summary` 和七个 `points`，不输出卡级 `evidence`。评分点证据保留具体问题和原文引用，修正建议写入 `EvalPoint.suggestion`。

## 维度与计分

覆盖序号连续性、引用标记正确性、列表层级一致性、标点规范性、排版一致性、表格格式和特殊格式正确性。

| 等级 | 评分点 | 综合分扣分 |
|---|---:|---:|
| `safe` | 100 | 0 |
| `minor` | 80 | 20 |
| `moderate` | 20 | 80 |
| `severe` | 0 | 100 |

综合分沿用安全评估器的扣分聚合：令 `d_i` 为各维度扣分，`M=max(d_i)`，`D=M+(Σd_i-M)/N`，其中 `N` 为维度总数，最终 `score=clamp(round(100-D),0,100)`。连续性、引用断裂和无法渲染的问题在 Prompt 中要求采用更高严重档；公式本身保持确定性和单调性。

## 边界与测试

判档前先定位成对三反引号或三波浪线的围栏边界，并从格式检查对象中排除围栏及其内部内容；仅存在于边界内部的命令编号、关键字和代码结构强制豁免，对应连续性维度的 `severity` 必须填写 `safe`，不得作为非安全证据，也不得出现理由写“判 safe”但字段填其他等级的矛盾。纯自然段无需强制套用标题、列表或表格格式。

重复编号、断号或跳号至少判 `numbering_continuity=moderate`，造成顺序歧义或结构无法追踪时判 `severe`。父标题下的列表项或操作步骤可以使用不同编号体系，但每层内部必须一致；标题或小节标题同时混用三种及以上不兼容标记族时，即使看似处于不同层级、读者仍能猜出层级，也必须判 `layout_consistency=severe`。在同一份文档的标题层级中，Markdown 标题标记与不缩进的中文序号标题、字母序号标题共同承担章节/小节标题作用时，视为不兼容标题体系；三类或以上标记族同时出现时不得把中文序号或字母行降格为普通列表。孤立标点误用通常为 `minor`，但引号、括号或书名号明显缺少闭合符号时至少为 `moderate`；同一短段系统性交替使用多套不兼容标点体系至少为 `moderate`，多类混用共同破坏一致性时为 `severe`。同段用三种及以上不兼容表示法表达同一类日期、货币或数值数据时，特殊格式维度至少为 `moderate`。采用严格 Markdown 表格规范时，表头、分隔行和数据行必须保持相同列数并具有完整列界；任一行缺少必要列界或无法严格对应列时，表格维度至少为 `moderate`。多个独立格式问题必须逐维返回，不能只报告最显眼的一项。

专项测试保留需求自带 14 条格式样例，通过注入 Judge 离散 verdict 验证阈值、细则证据和输出契约，不调用外部模型。

## 关键维度与普通维度

`numbering_continuity`（序号连续性）和 `citation_mark_correctness`（引用标记正确性）属于关键维度。跳号、重复编号、引用断开或引用目标不存在会直接破坏文档结构或可追溯性，因此关键维度按 100 的扣分权重计算。

关键权重不代表所有引用样式差异都应判为严重问题：引用样式不统一但仍可准确追溯时通常判 `minor`；引用目标不存在、正文与参考文献无法对应或引用链断开时判 `moderate` 或 `severe`。

`list_hierarchy`、`punctuation_standardization`、`layout_consistency`、`tabular_format` 和 `special_format_correctness` 属于普通维度，按 90 的扣分权重计算。普通维度仍会逐项扣分，但同等严重程度下影响略低于关键维度。

综合分继续采用“最大扣分完整计入，其余扣分按维度总数均摊追加”的公式：关键维度扣分为 `100 × (100-s)/100`，普通维度扣分为 `90 × (100-s)/100`，`D = max(d_i) + (Σd_i-max(d_i))/N`，最终 `score = clamp(round(100-D), 0, 100)`。
