# Benchmark 业务配置文件：需求分析

SWE-bench 的数据来源、自动导入、镜像策略和 Benchmark 调度策略分散在平台、执行客户端及 Evaluator 的环境变量中。部署者难以确定消费进程，也容易把客户端配置写到平台机而不生效。

将业务配置放到项目 `config/benchmark/`，按平台、评测和执行客户端独立管理；环境变量继续承担端口、数据库、密钥、运行目录和通信地址等部署参数。配置文件不设置 `version` 字段。

默认自动导入 SWE-bench Verified，允许关闭启动自动导入；已有完整数据集跳过准备，导入失败只警告并继续启动。旧业务变量不再覆盖配置，明确提示迁移。平台通信地址现有热更新机制保留。

不新增 API 或修改数据库结构，不修改 Benchmark 接入包的能力声明。仅运行专项测试，不启动浏览器验收。
