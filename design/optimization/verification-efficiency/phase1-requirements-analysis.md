# Skill 优化校验成本与有效性

## 问题与目标

质量校验串行执行错误用途的触发用例，旧版结果仅在进程内缓存，静态评估在检查修复及收尾各执行一次。目标是在保留结构检查、有效行为防回归和静态门禁的前提下，减少 Agent 执行、模型请求和等待。

## 验收

- 触发标签、should_trigger 字段及历史触发标准答案均不进入行为重评。
- 优先关联实验用例；不同客户端/自定义评估器不能偷换为本地默认评分，明确待原实验复测。
- 同条件旧版结果可跨重启复用；用例、文件、运行/评分配置变化时失效。
- 标准答案可参与有效评分；无标准或评分失败不得伪装为零分通过。
- 不变候选仅一次静态评估；变化后重新评估；失败/partial 不缓存。
- 进度和历史恢复能区分通过、跳过、未完成；完成单测、集成与浏览器正常及边界流程。
