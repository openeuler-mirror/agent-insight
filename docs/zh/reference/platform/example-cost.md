# 内置示例走查的成本参考

[内置示例端到端走查](../../tutorial/platform/02-example-walkthrough.md) 会带你用内置示例把核心闭环跑一遍。本页
保留原文记录的 **deepseek-v4-flash** 模型下 **Skill 生成 → 评测 → Skill 优化** 三个阶段的历史花费，
用于说明成本构成，不作为当前版本或服务商报价。

> **Note**
> 原记录未保存测量日期、代码提交、服务商价格版本和精确用例配置，当前无法复现核价。下面的数字是原文记载的一次结果（约 10–18 条用例），仅供理解成本组成；2026-10-27 的文档整理没有重新调用模型测量。

---

## 历史样例：一次完整闭环 ≈ 3.5–4 元

原记录在 **deepseek-v4-flash** 下完成 **Skill 生成 → 评测（含静态分析、触发分析、A/B 测试）
→ Skill 优化**，将 **3.5–4 元**作为当时的估计范围。当前工作台的入口和实际调用次数可能不同，应按实际运行重新统计。

---

## 各阶段花费占比

| 阶段 | 实测花费 | 占比 |
| --- | ---: | ---: |
| Skill 生成 | 0.16 | ~5% |
| 静态分析 | &lt;0.01 | ~0% |
| 触发分析（用例生成 + 运行） | 0.13 | ~4% |
| A/B 测试 — 执行 | 0.92 | ~27% |
| A/B 测试 — 评估 | 1.89 | ~56% |
| Skill 优化 | 0.25 | ~7% |
| **合计** | **约 3.4** | 100% |

> 表内单位为人民币元，合计约 3.4 元；3.5–4 元是原记录给出的估计范围，不是对当前成本的保证。

## 测量条件

- **模型标识**：deepseek-v4-flash（沿用原记录，未核验当前服务商映射）
- **示例**：内置示例端到端走查（见 [example-walkthrough](../../tutorial/platform/02-example-walkthrough.md)）
- **测量日期、代码版本、服务商及单价版本**：原记录未提供。
- **用例数与配置**：只记录约 10–18 条；精确数据集、评估器数量、重试、缓存命中和并发设置未提供。

## 为当前运行估算成本

先固定模型服务商、模型版本、数据集、评估器和重试配置，再用小规模样例记录各阶段的输入、输出及缓存 Token。按服务商对应计费规则计算各项费用，汇总生成、执行、评估、优化和失败重试的实际消耗，并用账单核对。记录测量日期、代码提交和配置，后续比较才有依据。
