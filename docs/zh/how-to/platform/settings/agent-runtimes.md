<a id="agent-runtime"></a>
Agent 运行时页用于查看当前平台服务部署环境中可访问的 Agent 运行时，并保存个人默认值。入口为
**配置 → Agent 运行时**。

> **Note**
> 当前版本只完成运行时探测、诊断与个人默认值保存。平台内置功能的执行仍统一使用 OpenCode，
> 其他运行时需要先提供执行适配器才会参与执行。

## 功能定位

页面承担三项职责：

- 探测当前服务进程可访问的运行时安装，展示版本、来源和可执行路径；
- 判定兼容性与执行能力，给出不可用原因；
- 保存或清除当前账号的个人默认运行时。

运行时可切换用于缩小平台执行与用户真实 Agent 使用方式的差异，不承诺不同运行时的结果一致。

## 检测范围

检测只覆盖**平台服务实际可访问的部署环境**：

- 容器内检测结果不代表宿主机或用户浏览器所在电脑的安装情况；
- 检测不调用真实模型，也不自动安装或升级依赖；
- 找到可执行文件不等于具备平台执行能力。

查找顺序为：部署侧环境变量 → 安装根下的 bundled 可执行文件 → 系统 `PATH`。显式配置的路径不存在
时直接报告该错误，不回落到其他来源。

| 运行时 | 环境变量 | bundled 路径 | 最低版本 |
| --- | --- | --- | --- |
| OpenCode | `OPENCODE_BIN` | `node_modules/.bin/opencode` | 1.14.30 |
| Pi | `AGENT_RUNTIME_PI_BIN` | `node_modules/.bin/pi` | 0.82.1 |

版本通过 `<可执行文件> --version` 读取，单次超时 3 秒；无法解析版本时不视为兼容。

## 可用性判定

只有同时满足以下条件的运行时才可被选择：

1. 找到可执行文件；
2. 版本可读取且不低于最低版本；
3. 平台已提供该运行时的执行适配器。

不可用原因是排他的，按以下顺序只展示第一条：

| 原因 | 含义 |
| --- | --- |
| 显式配置路径不存在 | 环境变量指向的路径不存在或不可执行 |
| 未安装 | 在环境变量、bundled 路径和 `PATH` 中都没有找到 |
| 版本不可读 | 找到可执行文件，但 `--version` 失败或超时 |
| 版本不兼容 | 实际版本低于最低要求 |
| 无执行适配器 | 找到可执行文件，但平台不能用它执行任务 |

当前版本中 OpenCode 提供执行适配器；Pi 可以被检测和展示，但因缺少适配器不可选择，也不展示
能力列表。

## 页面操作

### 查看检测结果

页面展示每个运行时的名称、状态、版本、来源、可执行路径与能力标签。检测结果缓存 30 秒。

### 重新检测

点击**重新检测**会跳过缓存重新执行探测，用于安装或调整路径后刷新结果。

### 保存个人默认值

选择**平台默认**或任一可用运行时后点击**保存**：

- 平台默认表示不保存个人偏好，由部署侧决定；
- 不可用的运行时不可选择，也不会被保存；
- 保存只写入当前账号，不修改部署环境或其他用户；
- 个人默认值只影响新任务和新会话，进行中的任务和历史会话保持原运行时绑定。

当前版本保存的偏好仅作为记录，尚不改变平台执行路径；接入执行服务后才会参与运行时选择。

## 故障排查

- **所有运行时显示未安装**：确认服务容器内实际安装了运行时，或通过环境变量指定绝对路径。
- **显式配置路径不存在**：检查环境变量是否指向存在的可执行文件；修正后重新检测。
- **版本不兼容**：升级运行时到最低版本以上；平台不会自动升级。
- **找到 Pi 但不可用**：这是预期行为，当前版本尚未提供 Pi 执行适配器。
- **宿主机已安装但页面未检测到**：平台检测的是服务进程所在环境，不是宿主机或浏览器电脑。
