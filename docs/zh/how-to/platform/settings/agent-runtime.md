# Agent 运行时

**配置 → Agent 运行时** 用来确认平台内置的 Skill 生成、优化、诊断和内部评测任务由哪个 Agent 执行。

页面只检测**平台服务进程自身可访问**的部署环境。容器内看到的结果不代表宿主机，也不代表浏览器所在电脑； Kubernetes 或 Docker 部署需要在服务所在容器或 Pod 内安装对应运行时。

## 查看检测结果

进入页面后自动检测一次，也可以点 **重新检测** 强制刷新。每张运行时卡片展示：

- **状态**：`可用`、`未安装`、`未适配`、`检测失败`、`版本不兼容`。
- **版本**与**最低版本**：低于最低版本的安装不会被视为可用。
- **可执行文件**与**来源**：环境变量、平台内置包或 `PATH`。
- **能力**：工具策略、会话续接、取消确认、超时回收、Skill 加载、Trace 归属。
- **原因**：不可用时给出具体说明。

找到可执行文件不等于可用于平台任务。只有平台已交付执行适配器、版本兼容的运行时才可选择。当前 OpenCode 已适配；检测到的 Pi 会显示为 **未适配**，不能选择。

检测只执行固定的 `--version` 探测，不调用模型、不发起网络请求，也不会自动安装或升级依赖。

## 保存个人默认值

选择**平台默认（自动）**或某个可用运行时后点 **保存**：

- **平台默认（自动）**：按目录顺序选择第一个**可选**运行时（Pi 优先，其次 OpenCode），未适配的运行时不会被选中。当前实际生效的是 OpenCode。
- **个人默认值**：只对当前账号生效，优先于平台默认顺序。

保存后只影响**之后新建的任务和会话**。进行中的任务与历史会话保持原运行时绑定，不会跨引擎复用原生 Session ID，也不会改写已有 Trace、评测结果或历史记录。

如果已保存的运行时后来变得不可用（被卸载、降级或缺少适配器），新任务会明确报错并提示重新选择，**不会静默改回其他引擎**，也不会放宽工具或权限限制。

## 状态排查

| 状态 | 处理方式 |
|-|-|
| 未安装 | 在服务所在环境中按该运行时的官方方式安装，或配置对应环境变量后重新检测 |
| 检测失败 | 确认可执行文件能直接运行 `--version`；容器内缺少依赖、文件不可执行或探测超时会报此状态 |
| 版本不兼容 | 升级到最低版本以上；平台不会对未验证的旧版本放行 |
| 未适配 | 平台尚未交付该运行时的执行适配器，先选择 OpenCode |

常见可执行文件覆盖变量：

- OpenCode：`OPENCODE_BIN`，未设置时依次使用平台包内的 `node_modules/.bin/opencode` 和 `PATH`。
- Pi：`AGENT_INSIGHT_PI_EXECUTABLE` 或 `PI_EXECUTABLE`，未设置时使用 `PATH`。

## 能力边界

运行时选择用于缩小平台执行与用户真实 Agent 使用方式之间的差异，**不承诺不同运行时得到完全一致的结果**。工具集合、上下文管理和 Skill 加载方式不同，输出与耗时都可能不同。

普通无工具 Judge 继续使用直连模型路径，不受本页设置影响；外部客户端上的被测 Agent 和 Benchmark 执行端仍使用各自的选择机制。

接口与状态码语义见[Agent 运行时参考](../../../reference/platform/agent-runtime.md)。
