AgentInsight · AgentRAS · AgentFI 逻辑关系

产品级逻辑图 · 角色优先 · 不按进程/目录命名

三个名字对应三类能力：AgentInsight 是平台；AgentRAS / AgentFI 是本机功能侧。前端、表结构、HTTP 契约一律属 Insight。

一句话：Insight 拥有产品面与数据面；RAS 做环内检测恢复并旁路上报；FI 以 Client 角色认领实验、注入采集并回传结果。

AgentInsight = 平台 AgentRAS = 可靠性模块 AgentFI = 注入模块 + FI Client

2. 逻辑关系边（读图用）

从到关系通道

AgentRASAgentInsight旁路上报异常事件（fail-open）① ras-events（非 OTLP）

AgentInsightAgentFI（FI Client）claim 响应下发 runs（虚线回程）②
AgentFIAgent 宿主挂载插件/hooker 并驱动被测执行本机编排

AgentRASAgentFI无直接依赖；同机可并存，经 Insight 观测面汇聚—
OTel 是 Insight 既有主观测进水管；RAS/FI 是另两条业务口径。三者最终多写入 Prisma，不是互相替换。
