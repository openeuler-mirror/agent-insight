# SDK 总览

Agent Insight 提供 Python 与 JavaScript / TypeScript 两套官方 SDK，二者能力对等，
封装了三件事：

- **追踪上报**：把函数调用、LLM 请求、自定义 Span 上报到 Agent Insight
- **数据集与评测**：通过代码创建数据集、提交评测任务、读取结果
- **Skills 调用**：从代码调用已发布的 Skills、传入变量、获取版本化输出

<Note>
  如果你只需要把现有应用的 LLM 调用纳入追踪，看 [通过 SDK 埋点](./trace-with-sdk)
  足够；如果你要做平台级集成（CI 跑评测、自建工具链），建议读完本页再继续。
</Note>

## 能力对照

| 能力 | Python SDK | JS/TS SDK | REST API |
| --- | :-: | :-: | :-: |
| 追踪装饰器 / 包装器 | ✅ `@trace` | ✅ `trace(fn)` | — |
| 手动 Span | ✅ | ✅ | ✅ |
| 数据集 CRUD | ✅ | ✅ | ✅ |
| 评测任务提交 | ✅ | ✅ | ✅ |
| Skills 调用 | ✅ | ✅ | ✅ |
| 异步流式上报 | ✅ | ✅ | — |

REST API 是所有 SDK 的底层依赖，**对于本身不是 Python / JS 的服务**（Go、Rust、
Java 等），可以直接调 REST API；详见 [REST API 参考](./reference/api)。

## 三种使用模式

### 模式一：装饰器（推荐用于函数级追踪）

最简洁，把整个函数的输入、输出、耗时上报为一个 Span：

<Tabs>
  <Tab title="Python">
    ```python
    from agent_insight import trace

    @trace
    def retrieve(query: str) -> list[str]:
        ...
    ```
  </Tab>
  <Tab title="JavaScript / TypeScript">
    ```ts
    import { trace } from "agent-insight";

    const retrieve = trace(async (query: string) => {
      // ...
    });
    ```
  </Tab>
</Tabs>

### 模式二：上下文管理器（适合代码块级埋点）

当你想为一段逻辑分组、加自定义标签时：

<Tabs>
  <Tab title="Python">
    ```python
    from agent_insight import span

    with span("rerank", tags=["v2"]) as s:
        results = my_rerank_fn(docs)
        s.add_metadata({"doc_count": len(results)})
    ```
  </Tab>
  <Tab title="JavaScript / TypeScript">
    ```ts
    import { withSpan } from "agent-insight";

    await withSpan("rerank", { tags: ["v2"] }, async (s) => {
      const results = await myRerankFn(docs);
      s.addMetadata({ docCount: results.length });
    });
    ```
  </Tab>
</Tabs>

### 模式三：底层 Client API（适合平台集成）

跑评测、管理数据集这类操作直接走 client：

<Tabs>
  <Tab title="Python">
    ```python
    dataset = client.datasets.create(name="qa-eval-v1")
    client.datasets.add_examples(dataset.id, examples=[...])

    experiment = client.evaluations.run(
        dataset_id=dataset.id,
        evaluators=["llm-judge:helpfulness", "code:exact-match"],
        target=my_agent_fn,
    )
    print(experiment.summary())
    ```
  </Tab>
  <Tab title="JavaScript / TypeScript">
    ```ts
    const dataset = await client.datasets.create({ name: "qa-eval-v1" });
    await client.datasets.addExamples(dataset.id, [/* ... */]);

    const experiment = await client.evaluations.run({
      datasetId: dataset.id,
      evaluators: ["llm-judge:helpfulness", "code:exact-match"],
      target: myAgentFn,
    });
    console.log(await experiment.summary());
    ```
  </Tab>
</Tabs>

## 错误处理与可靠性

<Warning>
  默认情况下，SDK 的上报失败**不会**抛出异常——为了避免可观测层影响业务。
  如需在 CI 或测试中显式校验上报，设置 `AGENT_INSIGHT_RAISE_ON_ERROR=1`。
</Warning>

- 上报采用**异步批量**：默认 5 秒或 100 条 flush 一次
- 进程退出时自动 flush；如有疑虑可显式 `client.flush()` / `await client.flush()`
- 服务端不可达时本地缓冲到队列上限（默认 10000 条）后开始丢弃
