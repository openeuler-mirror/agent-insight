# 客观答案匹配评估器

评估器 ID `preset-similarity-answer-match`，执行入口 `runAnswerMatch`，源码 `similarity-answer-match-evaluator.ts`。

## 目标与输入

判断客观问答中 Agent 回答是否覆盖标准答案的核心内容，适用于有唯/标准参考答案的结果验收。输入为 `actualOutput`（模型回答）与 `referenceOutput`（标准答案），`caseInput`（用户问题）作为 LLM 判同时的语境参考。未标注标准答案时直接返回不计分结果、不调用模型——只展示原因，不进综合分与类目均分，不产生 0 分。

## 判定流程

四个阶段，能确定命中的先由代码判定，不能确定的才交给 Judge。

### 1 关键信息点提取（LLM）

从标准答案提取回答该问题时必须覆盖的信息点，类型限定四类：

| type | 含义 | 示例 |
|---|---|---|
| `number` | 关键数值 | `42`、`3.14`、`2024 年` |
| `term` | 专有名词 | `Transformer`、`H2O` |
| `conclusion` | 核心结论 | 「X 大于 Y」 |
| `condition` | 必要条件 | 「温度不能超过 100℃」 |

并列要点拆成多个信息点（回答可能只命中其中部分），无关修饰不提取。`points` 非数组或类型越界抛 `SimilarityJudgeParseError`。提取不到任何信息点时返回不计分结果，且不再进行后续判同。

### 2 代码层精确匹配

无模型参与，命中即定档：

- `number`：同时提取阿拉伯数字（支持千分位逗号与小数）与中文数字（`四十二`、`一百亿`、`两`），以信息点文本中提取到的第一个数值（阿拉伯数字优先、各自按出现顺序）为期望值，与回答数值相差 `<1e-6` 视为完全覆盖（`42`/`42.0`/`四十二` 等价）；回答数值是标准数值的前缀截断（`3.14` vs `3.14159`）视为部分覆盖。
- `term`：去掉空白、`-`、`_` 后做大小写不敏感的子串命中，命中即完全覆盖。

`conclusion` 与 `condition` 不参与代码匹配，直接进入判同。

### 3 LLM 层语义判同

未代码命中的信息点交 Judge 逐点判定，返回按序号严格对齐的 `judgments`（`matched` / `not_matched` / `uncertain`）。序号越界、判定值非法或漏返某个信息点一律抛 `SimilarityJudgeParseError`（可重试），不把「漏返」静默当成未覆盖而扣分。同义转述、主被动变换、信息合并或拆分按覆盖处理；`matched` → 100/covered，`not_matched` 与 `uncertain` → 0/missing（证据分别写明「判定不匹配」「判定不确定」，与代码层未命中区分）。部分覆盖只可能由代码层数值截断产生。

### 4 综合评分

见下节。

## 计分

```text
base      = round( Σ 信息点得分 / 信息点数 )        # covered 100 / partial 50 / missing 0
deduction = 缺失 conclusion 数 × 10 + 缺失 number 数 × 20
score     = clamp(round(base - deduction), 0, 100)
若 base > 50 且存在缺失的 conclusion：score = min(score, 60)
verdict   = score >= 80 ? pass : score >= 60 ? warn : fail
```

逐点均值给出覆盖基准，再对两类高价值缺失额外扣分：关键数值是客观题的硬答案，缺失扣分重于核心结论，且都比重算均值更直接地压低总分。`base > 50` 时的 60 分上限针对「多数信息点命中但核心结论丢失」——结论缺失的回答不构成对问题的有效回答，不应因其余信息点大量命中而拿到高分。

## 输出

卡片输出 `verdict`、`summary`、`score`、`points`、`evidence`。`points` 每个信息点一条，label 为 `类型：信息点文本`（文本截断 80 字），score 与 status 取匹配结果，逐点证据写明该点走代码层还是 LLM 层及原因；卡级 `evidence` 汇总综合评分（含覆盖基准 `base` 与扣分调整）与逐信息点判定。`summary` 说明覆盖数 / 总数与遗漏项（最多列两项）。

## 边界与测试

空标准答案、标准答案提取不出信息点两种边界都不记分且不显示 0 分，后者只调用提取、不调用判同。回答正确但附带无关信息不扣分，语序完全不同而语义相同的结论按覆盖处理。专项测试在 judge 边界依次注入提取与判同两次返回，覆盖需求自带的十条用例、数值等价与截断、结论缺失扣分与 60 分上限，以及漏返 / 越界 / 非法枚举三类解析错误。
