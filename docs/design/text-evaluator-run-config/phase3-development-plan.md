# 文本评估器运行配置：开发计划

## 1. 配置契约与持久化

- 新增共享配置类型、默认值、校验、序列化、解析和摘要函数。
- 为 `Experiment` 增加 `evaluatorConfigsJson` 字段并更新 Prisma Client。
- 修改实验创建和详情接口，接收并返回配置。

## 2. 页面交互

- 新增文本评估器配置弹窗。
- 在新建实验评估器卡片中接入选择、配置、摘要和恢复默认。
- 在实验总览和 Case 详情展示配置摘要。

## 3. 运行引擎

- 结果执行时读取所属实验的持久化配置。
- 扩展文本预置分发接口，将配置传给 Exact Match/F1 评分器。
- 在成功、输入格式错误和参考格式错误证据中记录实际配置。

## 4. 测试

- 配置契约：默认值、合法输入、非法字段、阈值边界和存储往返。
- API：创建时保存、详情返回和非法配置拒绝。
- 预置分发：大小写、标点、空白、全半角、模糊和子串模式。
- 执行引擎：持久化配置确实改变结果分数。
- 最后执行类型检查、相关测试和全量测试。

## 5. 文档与页面验收

- 更新用户指南和开发者指南。
- 更新桌面端到端验收清单，使 30 条 Trace 按配置分组运行。
- 自动化测试完成后，再由用户决定是否启动开发服务器执行浏览器验收。
