# 跨 Session 调用关系：需求分析

用户已确认：为自定义调用方式新增独立关系上报、后端调用链查询和步骤定位，保留现有 Trace 上报，在既有链路追踪列表中合并为一条 Trace，复用原详情树，不新增关系图界面。开发后使用 mock 脚本验证。

每次关系独立上报，同 eventId 重试幂等，乱序和 Trace 晚到均允许。关系由上报提供，步骤位置区分明确证据、候选、时间推定。无定位不丢失关系；不推断整项任务完成。

验收覆盖 A→B→C、重复调用、并发重试、冲突、授权隔离、晚到、工具/Shell 匹配、排序与撤回、原 Trace 不变。

有 fromLocator 时按定位结果展示父子关系；无 fromLocator 时兼容为顺序执行视图，各 Agent 在同一 Trace 内并列展示。顺序优先 observedAt，缺失时使用服务端接收顺序；展示顺序不代表已证实串行执行。
