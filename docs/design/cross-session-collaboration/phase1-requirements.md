# 跨 Session 协作：需求分析

以 docs1/cross-session-collaboration-trace-design.md v0.9 为验收基准。用户仅调用 events 接口增量上报联系，端点自动成为协作节点，不要求预登记或绑定；无 Trace 仍可查看关系。有原 Trace 时按明确会话编号关联，fromLocator 只负责步骤查找。原 Trace 列表、正文和父子关系保持不变。

新增协作列表、协作图和节点/连线详情。保留重复联系、循环、多父级、消息传递，显示来源和定位证据，不推断任务完成。已有明确原生调用支持只读自动图，不要求补报事件。撤销此前仅树合并和默认顺序展示的产品规则。
