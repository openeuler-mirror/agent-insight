# 跨 Session 调用关系：开发计划

1. 新增存储对象和独立 SQL 存储层，绑定和事件均事务幂等。
2. 严格 JSON/字段校验、认证、单实例速率限制及三条 API。
3. 只读 Trace 解析、定位状态机及分组时间匹配。
4. 临时 SQLite mock 脚本经实际 HTTP handler 验证（不提交临时脚本），补单元、日志及旧库升级回归并运行 npm run test。
5. 更新用户接入说明和开发契约，报告未验证范围。不上线、不新增关系图界面。

## 现有链路追踪验收补齐

在查询时将已绑定且正文可用的父子 Session 投影为一棵树，不改写原始 Session/Execution。列表在分页与计数前排除被合并的子 Trace，详情加载所有成员并保留原始交互索引。唯一工具/命令候选可在标明“候选”的步骤下展示；提供定位但无法匹配时在父 Agent 下展示并说明原因；未提供 fromLocator 时，将各 Agent 顺序并列放在同一 Trace 内。循环、多父级冲突、缺失正文及超限数据保留原列表，避免隐藏无法显示的数据。只使用已认证用户的关系。

验收使用独立父、子 Trace（不提供原生 task 或 subagent 标记），检查上报前两条、上报后一条、子 Agent 工具及正文可展开、重复上报不重复展示，并覆盖无定位、多层、冲突及分页计数。同步用户/开发指南，新建中文 commit，排除临时 mock 文件。
