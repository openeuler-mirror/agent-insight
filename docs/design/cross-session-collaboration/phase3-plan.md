# 跨 Session 协作：开发计划

1. 自动解析会话身份，取消显式绑定前置条件，保护授权与歧义处理。
2. 补齐自动关系与上报事件的只读图查询，接入自定义树合并入口。
3. 新增协作列表、关系图、节点和边详情，接入 Trace 页入口。
4. 无 Trace 上报、多层原生调用、循环/重复边、晚到、定位、分页与权限回归。
5. 通过 develop_start.sh 启动服务，在授权账号写入标识明确的测试 Trace，经 HTTP 上报验证；保存 mock 数据本地、不提交脚本。更新用户/开发指南并创建中文 commit。


## 2026-09-17 验收目标修正（用户已确认）
同一协作的原始 Trace 在链路列表合并为一条，详情包含全部成员。有 fromLocator 的关系按已解析调用步骤挂载 subagent；没有定位或无法确定唯一父级的成员按首次上报顺序并列展示。循环、回传事件保留在协作图，不作为强制父子依据。保留原始数据与 source=raw 查询；合并读取不影响其他框架上报及 Goal Plus 专用投影。测试覆盖无需绑定、步骤定位、无定位、循环、多级及分页列表只保留入口。
