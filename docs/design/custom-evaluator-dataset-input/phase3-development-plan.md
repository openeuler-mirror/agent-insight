# 自定义评估器数据集输入变量：开发计划

## 实现步骤

1. 扩展自定义评估器允许变量、占位符上下文和两条 Judge 执行路径。
2. 扩展评估器 requirement 与实验 case 门控。
3. 为 `ExperimentCase` 增加 `datasetInput`，贯通实验创建、数据集导入、运行与详情读取。
4. 为数据集匹配增加可关闭语义回退的选项，`dataset_input` 使用确定性匹配。
5. Trace 评测按每个自定义评估器的变量需求决定运行或不适用，并注入同一 case 的输入/预期输出。
6. 更新创建和编辑界面的字段按钮、校验信息、标签与文案。
7. 更新用户指南、开发者评估器契约和相关数据流说明。

## 测试

- 占位符替换与非法变量校验。
- 精确匹配、实际输入包含数据集输入、反向不匹配、最长项优先。
- `dataset_input` 单独依赖不要求预期输出；与 `reference_output` 组合时要求预期输出。
- 实验门控覆盖全部已选 case。
- 实验和 Trace 两条运行路径的上下文注入。
- 存量四变量评估器回归。

## 交付验证

先运行 `npm run test`。浏览器 golden path 与边界 case 按仓库规范在用户确认启动 dev server 后执行。
