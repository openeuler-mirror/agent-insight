# Phase 1：需求分析

## 背景

830 分支的普通实验会从评测数据集导入参考答案，但 `ExperimentCase` 只保存答案文本，
没有保存原数据集与数据项标识。任务完成度评估实时提取关键观点后，因此无法把结果写回原数据项缓存。

## 目标

- 普通实验创建时持久化数据集与数据项绑定。
- 评测执行时可用该绑定读取并修复关键观点缓存。
- 保持未从数据集导入的实验兼容。

## 非目标

- 不拆分数据集的 JSON 存储结构。
- 不回填全部历史实验或历史数据集。
- 不改变评估器打分口径。

## 验收标准

- 从数据集导入的实验可成功创建和执行。
- `ExperimentCase` 中保存数据集/Case 绑定。
- 缓存为空或失效时实时提取并写回；有效缓存直接复用。
