# Phase 2：需求设计

## 数据模型

为 `ExperimentCase` 增加可空的 `caseValuesJson String?`。字段保存实验 Case 的评测上下文快照；
普通实验当前仅写入内部键 `__agentInsightDatasetCase`，值包含 `datasetId` 与 `caseId`。

字段为可空，旧实验、手工标注参考答案及未绑定数据集的 Case 行为不变。数据库同步只新增列，
不删除或重写已有数据。

## 数据流

实验向导从数据集匹配参考答案时，将绑定随 Case 一并提交；创建接口写入
`caseValuesJson`。任务完成度评估读取绑定，优先复用有效缓存；缓存为空或哈希失效时实时提取，
成功后写回原数据项。提取器对非空参考答案返回空数组时，以完整参考答案作为单个关键观点兜底。

## 兼容与回滚

- 缺少绑定时继续实时提取，但不执行写回。
- 旧版本代码可忽略新增列；回滚代码时该列可以保留。
- 不使用 `--accept-data-loss`。
