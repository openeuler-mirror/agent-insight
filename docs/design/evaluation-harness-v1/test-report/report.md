## 补充复测：实验列表的新建入口

**前次测试遗漏说明**：前一轮浏览器实际走的是“评测数据集 → 使用此版本新建实验”，该路径能运行，但没有覆盖“实验列表 → 新建实验”的主入口。原报告中的“浏览器完整流程”只指已列出的数据集发起路径，不能据此认定所有入口都已验收。

**本次复现**：同一个 `harness-ui@example.test` 账号，从实验列表点击“新建实验”。页面 `/experiments/new` 第一轮仍是原普通 Trace 向导；数据集选择框只有“不选择数据集”，没有任何贷款业务验收集版本。浏览器断言“第一步至少有一个贷款业务验收集选项”失败。

**根因**：多轮版本目录和普通评测集使用不同的数据接口；此前仅在原向导上方放置了另一个“新建版本化多轮实验”链接，没有将实验列表的主入口接入版本化流程。这是入口整合遗漏，与账号中是否存在数据无关。

![复现：新建实验主入口的数据集下拉为空](screenshots/25-before-new-entry.png)

**修复**：`/experiments/new` 默认展示“多轮评测”，第一步直接读取并选择多轮评测集版本；原向导保留在“普通 Trace 评测”页签，继续支持普通数据集、已有 Trace 和在线客户端下发。实验列表按钮仍进入同一个新建页面，用户无需从数据集卡片绕行。Skill 工作台直接使用的嵌入式普通向导保持原有行为。
