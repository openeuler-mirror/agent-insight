# 实验评估器超时与重试配置：需求分析

## 1. 背景

新建实验已支持配置 Agent 执行时间，但用户无法在实验页面配置评估阶段的超时。用户主要使用自定义 LLM 评估器，部分慢模型无法在现有请求超时内完成评估。评估器数量增加后，当前全量卡片列表也不便查找。

本需求在现有实验向导中增加评估超时和失败重试配置，并以最小前端改动补充搜索、来源筛选和分页。

相关文档：[需求设计](phase2-requirements-design.md)、[开发计划](phase3-development-plan.md)、[已有文本评估器运行配置](../text-evaluator-run-config/phase2-requirements-design.md)。

## 2. 改动前实现与兼容约束

以下描述的是代码基线，不能直接视为新配置的产品默认值。

| 路径 | 现有策略 | 影响 |
| --- | --- | --- |
| 新建实验中的自定义 LLM Judge | `EXPERIMENT_JUDGE_TIMEOUT_MS` 默认 180 秒；SDK `maxRetries: 2`；直连失败可回退 OpenCode | 请求超时、SDK 重试与传输回退叠加 |
| 实验结果行 | 普通结果行每次尝试上限 300 秒；外层最多重试两次，退避 2/8 秒 | 只增加模型请求超时仍会被外层提前结束 |
| 部分结果类内置评估器 | 模型请求默认 300 秒；一次评估可能包含多次调用 | 请求时间不等于完整评估尝试时间 |
| Agent 轨迹质量 | 评分阶段 300 秒；建议阶段每次 420 秒、最多两次；结果行上限 1200 秒 | 需要保留分阶段行为和有效评分 |
| Benchmark 官方评测 | SWE-bench 默认 1800 秒，Zsoft L1 默认 900 秒；独立 Evaluator 服务执行 | 受到服务资源上限、派发与回收协议约束 |
| 另一“评测执行”入口的自定义评估器 | `CUSTOM_EVAL_LLM_TIMEOUT_MS` 默认 120 秒 | 与新建实验不是同一运行入口，不应混淆 |

当前实验外层超时使用 `Promise.race`；该超时包装本身不会取消底层工作。新增可配超时时，必须贯通取消和清理，防止超时后旧尝试仍运行，新重试又开始。

## 3. 目标与范围

1. 新建实验可选择“使用系统默认”或“统一配置”。
2. 配置项为每次评估尝试的超时秒数、失败后最多重试次数。
3. 已选且支持配置的 LLM 评估器可逐行单独设置，也可逐行恢复为上层策略；选择“使用系统默认”时仍可编辑，未单独修改的行展示各评估器自己的系统默认超时与重试次数。
4. 所有修改只影响本次实验，随“开始实验”提交；不修改评估器中心的默认定义。
5. 评估器列表增加名称/描述搜索、来源筛选、分页；跨页和跨筛选保留勾选。
6. 生效配置持久化，后台执行、失败重试、详情回显和复制实验正确使用配置。
7. 优先覆盖自定义 LLM 评估器；内置评估器仅在完成运行适配后声明支持。

## 4. 前端约束

- 保留当前四步向导、顶部实验摘要、现有卡片样式和页面底部“上一步 / 开始实验”。
- 评估运行设置放在评估器列表及分页下方，Agent 执行参数维持原位置。
- 使用文本线框图评审；不以高保真原型推动页面重构，不改成左右双栏。
- “评估器单独配置（可选）”使用行内输入，不新增弹窗；系统默认与统一配置两种模式下均可展开和编辑。
- 不设置该区域的“确认修改”“全部恢复”等底部按钮。
- 每行恢复按钮始终可点击，包括未修改过的行。
- 不新增“配置方式”列；最后一列为恢复操作。
- 页面不展开累计耗时说明，字段细节通过可键盘/触屏访问的提示呈现。

## 5. 不在本次范围

- 开放 Benchmark 官方评测超时或重试的页面覆盖。
- 改动代码评估器已有的匹配规则配置。
- 重构实验向导、评估器中心或 Agent 执行参数区域。
- 新增评估并发、整个实验总时长、模型连接参数等配置。
- 为评估器保存跨实验的个人默认设置。
- 同步改造另一个“评测执行”入口的界面或默认行为。

## 6. 核心验收场景

- 慢模型：自定义评估器设置 600 秒后，可超过原 180 秒请求或 300 秒结果行限制完成，不被旧限制提前截断。
- 重试：600 秒、重试 2 次表示最多三次尝试，每次独立计时；成功即停止。重试 0 次时没有隐藏 SDK 自动重试。
- 单独配置：统一 600 秒/2 次，某行改成 900 秒/1 次；上层变化不覆盖该行。
- 逐行恢复：恢复后超时和重试同时继承上层；无论是否修改过都可重复点击。
- 系统默认：无需选择统一配置即可展开“评估器单独配置（可选）”，每行填入各自系统默认的超时和重试数值，并可直接修改。
- 切换系统默认：已有单独配置保留；其他项显示并使用各自系统默认数值，恢复按钮变为“恢复系统默认”；点击恢复后两字段回到该评估器系统默认值。
- 选择：搜索、筛选、分页不丢失勾选；单独配置列表包含跨页的全部已选支持项。
- 兼容：旧实验及原文本匹配配置仍能读取、运行和重试；Benchmark 官方评测不受统一 LLM 设置影响。
