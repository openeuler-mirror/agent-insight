# Benchmark 业务配置文件：开发计划

1. 增加三份默认 YAML、统一加载与校验模块、本地覆盖忽略规则。
2. 接入启动自动导入、独立 Loader、平台调度、执行客户端 Git 策略和 Evaluator。
3. 保留环境参数，移除业务变量覆盖并提示迁移；更新启动警告的配置建议。
4. 将解析器与默认配置加入 npm、standalone、Controller/Runtime 和客户端制品；客户端升级保留本地覆盖。
5. 同步用户数据集指南与开发者部署指南。
6. 专项验证覆盖优先级、相对路径、空值/数组语义、字段错误、旧变量无效、关闭自动导入、失败不阻断、镜像策略、调度并发与独立制品分发。无需全量测试和浏览器验证。
