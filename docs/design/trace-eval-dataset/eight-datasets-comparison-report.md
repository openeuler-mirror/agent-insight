# 智能采样：最终效果对比报告

更新：2026-10-13。对应生产策略 `trace-coverage-v6.35`，当前目标以[需求分析](phase1-requirements-analysis.md)为准，算法见[需求设计](phase2-requirements-design.md)，产品验证见[开发计划](phase3-development-plan.md)。本报告只保留最终生产方案、适用指标及验证边界，不保留逐轮优化记录。

开发池的六项覆盖、四项主质量，以及五个新来源的五项覆盖、五项质量，均达到现行**均值**目标。独立统计、全平台真实 Trace、完整产品链路与生产压力验证仍未完成，因此不能据此宣布整体验收完成。

## 1. 比较对象与口径

智能采样从 Trace 结构中提取问答，按输入与回答双字段精确去重，再在预算与分布约束下扩大输入词项覆盖，并选择参考回答。它不调用 LLM，不验证输入的语义独立性或答案的事实正确性。公开数据实验将数据映射为问答候选，主要验证文本采样能力，不能替代真实工具行为与产品链路验证。

本报告区分两类比较：

| 比较 | 随机基线 | 可以支持的结论 |
| --- | --- | --- |
| 微软公开增幅与本地开发池增幅 | 两边分别使用各自实验的随机基线 | 比较公开数值；不是同候选池、同预处理、同随机实现的算法对决 |
| 本地智能采样与本地随机 | 同一冻结候选池、相同样本数，按固定种子运行 | 比较该候选池上选样结果的覆盖和已有人工评分 |

覆盖增幅按 `(智能采样平均独立词项数 / 随机平均独立词项数 − 1) × 100%` 计算；百分点差为两个增幅直接相减。独立词项数只计输入。人工质量使用数据集原有人工标注，**选样完成后**才读取标签，均值不代表模型经过训练后能力提升。

开发池按原始来源、分层及标注范围冻结，主要实验 K=100，种子为 42、100、101、102、103。六个词汇覆盖池各有 5,000 条候选。OASST2 主质量使用 `quality-annotated` 子池；SummarizeFeedback 按 CNN-DM/test、TLDR/valid2、TLDR/valid1 分层，不能与全池统计混用。

微软参考值来自 [Intelligent Sampling in Microsoft Foundry](https://techcommunity.microsoft.com/blog/azure-ai-foundry-blog/intelligent-sampling-in-microsoft-foundry-the-science-behind-selecting-better-pr/4523722)。本地来源、版本与下载范围见[来源清单](examples/eight-datasets/data-manifest.json)。即使数据集名称相同，也不表示快照、候选池、取数和预处理完全相同；ShareGPT-GPT4 的本地映射来源也必须以清单为准。

## 3. 五个新来源与同池随机比较

固定算法后完成 198 个场景、990 次方法运行，包含完整池 K=100、种子 200–219，以及 K=20/500 敏感性与来源面板。新来源统一只比较**同一候选池、相同样本数的均匀随机采样**，不套用微软增幅，也不要求超过随机额外 5 个百分点。

### 3.1 来源与覆盖

| 新来源 | 有效候选 / 来源组 | 随机词项数 | 智能采样词项数 | 相对随机增幅 | 当前目标 / 均值判定 |
| --- | ---: | ---: | ---: | ---: | --- |
| HelpSteer2 validation | 924 / 460 | 2,312.90 | 3,701.40 | +60.03% | >0% / 通过 |
| No Robots test | 489 / 489 | 2,236.95 | 3,215.35 | +43.74% | >0% / 通过 |
| OASST2 validation | 1,949 / 659 | 1,158.80 | 1,781.95 | +53.78% | >0% / 通过 |
| SummEval 新文章组 | 1,454 / 94 | 4,474.10 | 5,756.00 | +28.65% | >0% / 通过 |
| WildChat 新数据页 | 5,000 / 4,228 | 3,820.15 | 7,617.70 | +99.41% | >0% / 通过 |

各完整池 20/20 次满足实验的预算与分布约束。候选不足时使用实际数量，不复制数据补足 5,000。“五个新来源”不等于五个全新数据集：四个是已用数据集的新切分或新页，SummEval 是新增摘要数据集。

### 3.2 当前保留的质量目标

| 新来源 / 质量轴 | 同池随机 | 智能采样 | 分数变化 | 当前目标 / 均值判定 |
| --- | ---: | ---: | ---: | --- |
| OASST2 / quality | 0.667722 | 0.694855 | +0.027133 | 不低于随机 / 通过 |
| SummEval / coherence | 3.406361 | 3.756000 | +0.349639 | 不低于随机 −0.024 / 通过 |
| SummEval / consistency | 4.628333 | 4.939667 | +0.311333 | 不低于随机 / 通过 |
| SummEval / fluency | 4.640514 | 4.863208 | +0.222694 | 不低于随机 / 通过 |
| SummEval / relevance | 3.791931 | 4.123208 | +0.331278 | 不低于随机 / 通过 |

五项覆盖和五项质量的现行均值目标均通过。OASST2 quality 使用 0–1 量表，仅统计已标注的入选回答；随机与智能采样平均标注数量分别为 99.65、99.00，不能直接与开发池的已标注子池均值相比。SummEval 为 1–5 量表，不能套用 SummarizeFeedback 的 1–7 量表阈值。无人工标签来源不能据覆盖提升推断答案质量提升。

### 3.3 隔离与统计边界

来源隔离使用来源 ID、规范化输入、词法输入以及词项集 Jaccard ≥0.8 检查，并排除关联来源组；旧八源映射数据整体列入排除范围。这是可审计的词法隔离，不保证识别所有语义改写。选样输入与人工标签分文件，全部选样 ID 写出后才进行评分审计。

20 个种子反映同一池内的选样波动，不能当作 20 个独立业务来源。来源面板较少，且分池后采样比例变化，面板 bootstrap 区间不能冒充完整池均值差的置信区间。现有均值通过不等于总体显著优于随机或泛化验收通过。

UltraChat 新页因服务限流未取得完整数据；Dolly、ShareGPT-GPT4 及原 SummarizeFeedback 本轮未取得新的独立来源。五源也缺少真实工具轨迹。若用本批数据继续调参，它们即转为开发回归池，再次独立确认应另取数据。

## 5. 数据集用途与来源

八个开发数据集用于覆盖真实对话、人工指令、多轮社区对话、合成指令及带人工评分的回答/摘要。词汇覆盖衡量输入多样性，人工标注衡量选中样本的已有质量，不能互相替代。

| 数据集 | 自身用途 | 本报告中的验证作用 |
| --- | --- | --- |
| WildChat | 真实用户与聊天模型的对话 | 检查自然、长尾输入的词汇覆盖；新页验证迁移 |
| Dolly | 人工编写的指令与回答 | 检查多任务人工指令的词汇覆盖 |
| No Robots | 人工编写的高质量指令对话 | 检查人工指令覆盖，test 切分验证迁移 |
| OASST2 | 社区贡献的对话树与回答评分 | 检查词汇覆盖和已标注回答 quality，validation 验证迁移 |
| ShareGPT-GPT4 | 公开 GPT-4 对话数据 | 检查较长开放对话输入的覆盖 |
| UltraChat | 大规模合成多轮指令对话 | 检查合成指令的输入覆盖 |
| HelpSteer2 | 带多维人工属性标注的指令回答 | 保留为来源与覆盖验证；helpfulness、correctness 不作为当前目标或报告指标 |
| Summarize from Feedback | 摘要偏好与人工评价数据 | 按来源/切分检查摘要 overall 及细分质量 |
| SummEval（新增确认来源） | 专家评价的新闻摘要 | 检查新文章上的摘要质量迁移，量表与上项分开 |

八源具体仓库、修订、许可、下载范围及映射文件 SHA 以[开发池来源清单](examples/eight-datasets/data-manifest.json)为准；新来源以[下载清单](examples/v635-independent-20261013/download-manifest.json)与[候选池清单](examples/v635-independent-20261013/pool-manifest.json)为准。
