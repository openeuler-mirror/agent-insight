# Runtime 参数开发计划

1. 实现共享 YAML 加载、默认值覆盖、契约摘要、模板修订及 JSON 校验，区分执行端原生平铺/嵌套结构。
2. MCTS 默认值、Schema 和联调预设全部使用 CLI 原名，声明平铺 argv 直传，去除逐字段映射；保护平台调度参数并允许新增业务标量字段。
3. 树形/JSON 双视图按执行端声明限制可用类型和层级；完成 JSON 导入差异预览、导出、最终配置预览及不可变个人模板修订。
4. 贯通普通实验、Skill 客户端及 Benchmark 的创建、快照、复用、重试和下发，保留 JSON 文件/参数交付及已有映射模式。OpenCode 保持空定义，后续按其真实配置格式和入口接入。
5. 保留历史实验快照；旧 MCTS camelCase 仅在复用时展示名称转换预览，用户确认后产生新草稿，不静默改写或在执行器转换。
6. 同步分发安装链路及用户/开发者指南，说明新 CLI 参数仅在平台增加同名 key/value，默认值/预设/校验可选修改配置，升级代码需重新安装客户端。
7. 覆盖结构限制、CLI 原名和新增字段直传、保留字段、类型/边界、旧快照、复用确认、摘要漂移、普通及 MCTS 执行、并发文件隔离和失败清理；执行 `npm run test` 与相关类型/lint 检查。按用户选择暂不启动 dev，未在浏览器中验证。
