# 5 分钟上手

本指南将带你完成从零到看到第一条追踪的全过程。完成后你会得到：

- 一个可用的 Agent Insight 账号与 Workspace
- 一个已注册的 Agent，含独立 API Key
- 一个被追踪的智能体应用，链路数据实时呈现在 UI 中

<Note>
  仅需 5 分钟。如果只是想先看看产品长什么样，可以直接访问
  [在线 Demo](https://demo.agent-insight.example.com)，无需走完本流程。
</Note>

## 前置条件

- Python 3.9+ 或 Node.js 18+
- 一个可用的 LLM API Key（本示例使用 OpenAI，你也可以替换成任意支持的模型）
- 终端能正常访问外网

---

## 步骤一：注册并创建 Agent

1. 打开 [https://app.agent-insight.example.com](https://app.agent-insight.example.com) 并完成注册。
2. 登录后进入侧边栏 **AGENT WORKSPACE → Agent 管理**。
3. 点击 **+ 新建 Agent**，填入名称（如 `my-first-agent`）后保存。
4. 在 Agent 详情页复制 **API Key**，妥善保存——它只展示一次。

<Tip>
  推荐为每个环境（开发 / 预发 / 生产）创建独立 Agent，便于在追踪中按环境过滤。
</Tip>

## 步骤四：接入追踪

在你的应用代码中加入一行装饰器，函数调用就会自动上报到 Agent Insight。

<Tabs>
  <Tab title="Python">
    ```python
    from openai import OpenAI
    from agent_insight import trace

    client = OpenAI()

    @trace                           # ← 仅需这一行
    def ask(question: str) -> str:
        resp = client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": question}],
        )
        return resp.choices[0].message.content

    if __name__ == "__main__":
        print(ask("用一句话解释什么是可观测性"))
    ```
  </Tab>
  <Tab title="JavaScript / TypeScript">
    ```ts
    import OpenAI from "openai";
    import { trace } from "agent-insight";

    const client = new OpenAI();

    const ask = trace(async (question: string) => {     // ← 用 trace 包一层
      const resp = await client.chat.completions.create({
        model: "gpt-4o-mini",
        messages: [{ role: "user", content: question }],
      });
      return resp.choices[0].message.content;
    });

    console.log(await ask("用一句话解释什么是可观测性"));
    ```
  </Tab>
</Tabs>

运行这段代码，控制台会打印 LLM 的回答。

## 步骤五：在 UI 中查看追踪

回到 Agent Insight UI，进入 **运行观测 → 链路追踪**。你会看到刚才那次调用：

- **Trace 列表**展示请求时间、模型、Token 数、耗时
- 点击进入详情可查看完整的输入输出、Span 时间线、Token 用量分布

<Warning>
  如果 30 秒后仍未看到数据，请检查：

  1. 环境变量 `AGENT_INSIGHT_API_KEY` 是否在程序运行的 shell 中生效
  2. Agent 是否选对了对应的 Workspace
  3. 网络是否可访问 `app.agent-insight.example.com`

  排查无果可参考 [常见问题](./faq) 或联系支持。
</Warning>
