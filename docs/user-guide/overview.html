Agent Insight

Agent Insight是openEuler社区孵化的开源AgentOps平台，致力于构建「观测 → 评测 → 诊断 → 优化」持续运转的能力闭环，以及贯穿全流程的可靠性保障能力，将黑盒化的Agent转化为可观测、可度量、可治理的可信资产，使生产级Agent做到"行为看得清、故障诊得准、服务跑得稳"，并持续进化。目前，Agent Insight已适配OpenCode、Claude Code、Hermes、Trae IDE、JiuwenSwarm等12个主流Agent运行时。

03

快速开始

前置条件：Node.js ≥ 20；Python 3（仅 openGauss 模式需要）；可选 Docker。默认安装路径 ~/.agent-insight/，可用 AGENT_INSIGHT_DATA_DIR 覆盖，SQLite 文件位于 <dataRoot>/data/witty_insight.db。

1
安装
# 方式一：一键安装（推荐用于单机部署）npm install -g agent-insightagent-insight install # 方式二：从源码开发模式git clone https://gitcode.com/openeuler/agent-insight.gitcd agent-insightnpm installcp .env.example .env.localnpm run dev
postinstall.js 会把 .env.example 复制到 <dataRoot>/.env（若不存在），跑 prepare-ras-sqlite-schema.js 补齐 Agent RAS 相关表，再执行 prisma db push + prisma generate。
2
运行
# CLI 启动（生产/单机）agent-insight start # 默认端口 3000agent-insight start --port 3001 # 指定端口 # 源码开发模式npm run dev # next dev -p 3000 # Docker（amd64 / arm64）docker compose -f docker-compose.amd64.yml up -d # Docker（源码挂载模式）AGENT_INSIGHT_SOURCE_DIR=/src docker compose -f docker-compose.source.yml up -d

start.js 流程：解析端口 → 检查占用 → 跑 prepare-ras-sqlite-schema.js → 同步 DB schema → prisma db push + prisma generate → standalone 模式下把 .next/static、public 同步进 .next/standalone/（否则前端静态资源 404）→ 拉起 Next.js → 写回 admin API key。

control-server.js（standalone 专用）：Next 的 Route Handler 拿不到 HTTP upgrade 事件，Agent RAS 的远程控制通道因此不能做成普通 API 路由。standalone 模式下它接管 HTTP server：/api/reliability/client/v1/control 走 WebSocket，其余请求原样转发给 Next；端口见环境变量 AGENT_INSIGHT_RAS_DISPATCH_PORT（默认 PORT+1）。dev 模式没有这层，控制面回落到进程内 hub。
3
测试
npm run test # tsc 类型检查 + tsx --test test/**/*.test.tsnpm run test:skill # 单跑 Skill 生成器测试npm run lint # ESLint

测试覆盖 285+ 个 test 文件，主要在 test/ 下；测试命令会先跑 scripts/trae-collector/tsconfig.json 的类型检查。

部署方式配置文件说明

本地开发 scripts/develop_start.sh dev 模式 + Prisma dev DB
从源码打包 npm scripts/publish-npm.js npm whoami 校验 → npm ci → lint → npm run build → setupStandalone() → npm pack → npm publish --tag
