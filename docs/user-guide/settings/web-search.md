# 联网搜索

联网搜索用于配置平台访问外部公开信息源的方式，为需要补充公共资料的生成流程提供搜索与网页抓取能力。

> **Note**
> 当前实现中，联网搜索仅用于 **Skill 生成** 场景，为 Skill 起草过程补充公开信息；该能力不是全局推理、评测或诊断流程的通用依赖。

## 功能定位

联网搜索承担三项核心职责：

- 配置当前账号可用的联网搜索 Provider
- 保存联网搜索所需的 API Key
- 为 Skill 生成流程提供公共信息检索与页面正文提取能力

## 当前能力边界

当前版本的联网搜索具有明确边界：

- 作用范围：仅作用于 **Skill 生成**
- 信息类型：仅提供公开网络信息，不承诺私有数据访问能力
- 使用方式：作为生成流程的补充工具，而不是默认强依赖项

启用与禁用的影响如下：

- **启用后**：Skill 生成流程可在需要时调用搜索与页面抓取能力，补充公开资料
- **禁用后**：Skill 生成仍可执行，但仅依赖本地上下文、输入材料与已有参考信息

## 页面结构

联网搜索页面通常由三个功能区组成：

1. **Provider 配置区**
   用于选择搜索供应商并填写接入凭证。
2. **当前状态区**
   用于查看当前启用状态、Provider、API Key 配置状态以及可用工具。
3. **相关说明区**
   用于查看 Provider 文档、API Key 获取方式与联网搜索配置说明。

### Provider 配置区

Provider 配置区通常包含：

- **Provider 选择项**：用于选择当前启用的联网搜索供应商
- **API Key 输入框**：用于填写对应 Provider 的鉴权凭证
- **保存操作**：用于提交并持久化当前配置
- **说明提示区**：用于说明联网搜索的使用限制与建议场景

### 当前状态区

当前状态区通常包含：

- **启用状态**：显示当前是否已启用联网搜索
- **Provider**：显示当前生效的供应商
- **API Key 状态**：显示是否已经配置凭证
- **已注册工具**：显示生成流程可调用的联网工具，例如搜索与网页抓取

### 相关说明区

相关说明区通常包含：

- Provider 官方站点或控制台入口
- API Key 获取说明
- 联网搜索配置状态说明

## 关键配置项说明

| 配置项 | 说明 |
| --- | --- |
| **Provider** | 当前启用的联网搜索供应商，例如通用搜索 API 服务。 |
| **API Key** | 访问搜索供应商的鉴权凭证。 |
| **启用状态** | 当前账号下联网搜索是否已启用。 |
| **已注册工具** | Skill 生成流程可调用的联网能力，例如 `web_search` 与 `web_fetch`。 |
| **作用范围** | 当前仅对 Skill 生成流程生效。 |

## 工具能力说明

联网搜索启用后，Skill 生成流程通常可获得两类外部信息能力：

- **关键词搜索**
  用于查找与目标主题相关的公开网页与资料线索。
- **页面抓取与正文提取**
  用于读取目标网页正文，并将公开信息转化为生成上下文。

这两类能力的典型用途包括：

- 补充行业公开知识、产品文档或协议说明
- 获取目标主题的背景资料与术语解释
- 为 Skill 起草提供更完整的公共信息上下文

## 操作流程

### 流程一：启用联网搜索

1. 进入 **联网搜索** 页面。
2. 在 Provider 配置区选择目标搜索供应商。
3. 填写该供应商对应的 API Key。
4. 执行保存操作。
5. 在当前状态区确认启用状态、Provider 与 API Key 状态已更新。
6. 在后续 Skill 生成流程中验证联网能力是否可用。

### 流程二：更新联网搜索配置

1. 进入 **联网搜索** 页面。
2. 修改 Provider 或更新 API Key。
3. 执行保存操作。
4. 在当前状态区确认配置状态已刷新。
5. 在新的 Skill 生成流程中验证最新配置是否生效。

### 流程三：停用联网搜索

1. 进入 **联网搜索** 页面。
2. 将 Provider 切换为禁用状态或移除有效配置。
3. 执行保存操作。
4. 确认当前状态区已反映停用结果。
5. 后续 Skill 生成流程回退为仅使用本地上下文与已有参考资料。

## 生效机制

联网搜索配置通常在保存后对**后续新启动的 Skill 生成流程**生效，而不是强制刷新已在运行中的旧上下文。

这意味着：

- 已开始的旧生成流程通常不会自动切换到新配置
- 新的生成任务会读取最新 Provider 与 API Key
- 配置验证应在新的 Skill 生成任务中完成

## 启用建议

以下场景适合启用联网搜索：

- Skill 起草需要补充公开资料
- 目标主题依赖外部文档、标准、产品说明或公共背景信息
- 生成内容需要覆盖最新公开知识

以下场景更适合保持禁用：

- 任务仅依赖本地上下文即可完成
- 生成内容强调稳定复现与最小外部依赖
- 环境对外网访问有严格约束

## 维护建议

### 账号级隔离

当前配置主要作用于当前账号，不同账号可分别维护联网搜索配置，便于区分实验与正式使用场景。

### 受控启用

联网搜索建议按需启用，不建议作为所有生成任务的默认前提，以降低外部依赖、结果波动与额外成本。

### 新流程验证

配置变更后，建议通过新的 Skill 生成任务验证 Provider 可用性与信息补充效果，而不是依赖旧会话结果判断是否生效。

## 常见异常

### 已保存配置，但当前流程未立即生效

常见原因包括：

- 当前运行的是旧会话或旧流程上下文
- 新配置仅对后续新启动的 Skill 生成任务生效
- Provider 或 API Key 变更后尚未通过新流程验证

### 已启用联网搜索，但生成结果仍未使用外部资料

常见原因包括：

- 当前任务不需要联网补充信息
- Provider 配置不完整或 API Key 无效
- 外部检索结果不足以支撑有效补充
