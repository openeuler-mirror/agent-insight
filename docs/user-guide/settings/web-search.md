# 联网搜索

联网搜索页用于配置平台在特定场景下访问外部网络搜索能力的方式。

> **Note**
> 联网搜索不是所有流程的必需项，但在 Skills 生成等需要外部资料补充的场景里会非常有用。

## 这页能做什么

- 启用或禁用联网搜索
- 选择搜索供应商
- 配置 API Key
- 统一管理当前账号下的搜索能力

## 当前能力边界

从当前实现来看，联网搜索配置更偏向 Skills 生成等场景的辅助能力，而不是一个全局强依赖模块。

可以这样理解：

- **启用后**：部分需要外部信息补充的流程可以调用搜索工具
- **禁用后**：相关流程仍可运行，但不会主动发起外部网络搜索

## 配置项通常包括什么

### 供应商

你可以选择：

- 不启用
- 启用当前支持的搜索供应商

当前实现中，典型配置方式是选择具体 Provider 并填入对应 API Key。

### API Key

当选择启用供应商后，需要填写对应的 API Key。保存后，后续新的会话或流程才会读取最新配置。

### 生效范围

当前语义上，这项配置主要作用于**当前账号**。

这意味着：

- 不同账号可以有不同配置
- 你不必担心把个人测试配置直接影响到所有用户

## 什么时候建议启用

比较适合启用联网搜索的情况：

- 需要查找外部实时信息
- Skills 生成希望参考外部资料
- 任务本身依赖公开网络内容

不建议默认滥用的情况：

- 当前任务完全基于本地上下文即可完成
- 你希望严格限制外部网络访问
- 你更关心稳定复现和最小外部依赖

## 启用后的典型作用

联网搜索通常会给生成类或辅助类流程提供两类工具能力：

- 关键词搜索
- 页面抓取与正文提取

这类能力可以帮助平台：

- 先找到可能相关的公开资料
- 再读取页面正文作为额外上下文

## 禁用后会发生什么

禁用联网搜索通常意味着：

- 不再发起任何外部搜索请求
- 依赖搜索的能力只使用本地已有上下文
- 某些生成结果可能更保守，但可控性更高

这对安全敏感或内网环境尤其有价值。

## 推荐使用方式

### 用于 Skills 生成

这是最典型的场景：

1. 先配置 Provider 和 API Key
2. 在生成 Skill 时按需打开联网搜索
3. 仅在确实需要外部资料的场景启用

### 用于受控实验

如果你不确定联网搜索是否值得长期启用，可以先在小范围场景试验，再决定是否长期保留。

## 常见问题

### 为什么我已经配置了联网搜索，但当前页面没有立刻生效？

当前配置通常在保存后，对**下一轮会话或下一次流程启动**生效，而不是强制刷新当前正在运行的上下文。

### 为什么建议不要默认一直开启？

因为联网搜索会引入：

- 外部依赖
- 结果不稳定性
- 额外成本
- 额外安全考虑

只有在确实需要外部资料时启用，通常更合理。
