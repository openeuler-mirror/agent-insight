# 质量监控

质量监控按 Agent 和时间窗口汇总 trace，将运行质量拆成过程、成本和错误三个维度。它只读取已落库的运行信号和轨迹分析数据，不评判最终答案，也不会因为 trace 上传而自动调用结果评估器。

## 如何使用

1. 在页面顶部选择 Agent、时间窗和可选 Skill。
2. 查看综合分以及过程、成本、错误三张维度卡，定位工具错误、步骤效率、成本预算或安全信号。
3. 使用趋势、过程分析和统一问题汇总确定异常开始时间与高影响问题。
4. 在执行记录中查看确定性运行质量分和工具、成本、安全信号，并点击记录下钻 trace。

如果需要评判最终答案的任务完成度、准确性、答案质量、忠实度、指令遵循或轨迹质量，请在[评估与实验](../evaluation/evaluators)主动创建并运行实验。评估与实验中的评估器与质量监控相互独立。
