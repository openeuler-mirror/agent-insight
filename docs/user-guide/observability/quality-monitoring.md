# 质量监控

质量监控按 Agent 和时间窗口汇总 trace，将质量拆成结果、过程、成本和错误四个维度。页面只读取已落库评测，打开报告时不会临时调用评测模型。

## 结果评测

“结果”只评 Agent 的最终交付，不重复评价工具选择或步骤顺序。它包含四项：

- **忠实度**：先把最终结果拆成可验证主张，再逐条核对链路追踪中最终 Agent 可见的工具输出。展开指标可查看原文证据；无工具证据或无可验证主张时为 N/A。
- **指令遵循**：是否满足明确的输出契约，例如格式、语言、长度、字段、关键词、章节、精确数量、禁止事项、范围和风格。普通业务问题不会被重复算作输出约束；无明确输出约束时为 N/A。
- **答案质量**：分别评价每条陈述与任务的相关性、各个业务必答要点的完整性，以及表达的连贯性，再按 30%/50%/20% 汇总。它不评价格式和语言等输出契约。
- **准确性**：将 trace 输入匹配到带预期输出的评测数据集 Case，复用预期输出中缓存的关键观点，将完整最终答案交给准确性评测器逐项判断。已表达但错误的观点和额外编造内容会扣分；未提及的观点不扣准确率，由答案质量中的完整性负责。没有匹配 Case 或预期关键观点时为 N/A。

结果总分是四项有效指标的等权平均。N/A 不会被当作 0 分，页面会同时显示覆盖率和置信度。

## 如何使用

1. 在页面顶部选择 Agent、时间窗和可选 Skill。
2. 先看综合分和四维卡片；覆盖不足时，不要把 N/A 理解为质量差。
3. 打开“结果评测”查看四项分数、覆盖率、置信度和 trace 级证据摘要。忠实度和准确性会展示 trace 得分并保留原因总结，点击“评测详情”可查看主张裁决、关键观点裁决和额外错误等结构化表格。指令遵循会展示得分和约束满足数；没有明确输出约束的 trace 直接显示“不适用”且不展示空详情表。答案质量会展示总分、相关性、完整性和连贯性子分。
4. 在执行记录中区分“评测中”、“评测失败”、N/A 和真实低分，并点击记录下钻 trace。

## 覆盖率与回填

新上传的完整 trace 会异步触发结果评测。历史 trace 可通过质量回填入口按预算补评；回填过程不阻塞质量报告查询。准确性需要 [评测数据集](../evaluation/datasets)中存在 input 可匹配且带预期输出的 Case。修改预期输出、关键观点或数据集后，相关历史准确率会进入重新评测范围。
