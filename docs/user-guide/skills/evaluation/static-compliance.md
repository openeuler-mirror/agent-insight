# Skill 评估

**Skill 评估**对顶部选中的 Skill 文件快照执行静态质量检查。它关注 Skill 是否写得清晰、完整、安全且可执行，不运行真实任务；真实效果需要到 **Skill 实验**验证。

该页既支持正式版本，也支持生成或优化产生的未发布快照。

页面主要包括：

- **静态质量评估摘要**：标明当前对象是正式版本还是未发布快照。
- **质量门禁**：显示通过、未通过、评估中、失败、过期或尚未评估。
- **开始评估 / 重新评估**：对当前固定快照运行检查。
- **AI 修复高风险问题**：把本次高风险问题交给优化 Agent。
- **维度得分**：按 5 分制展示各质量维度。
- **问题清单**：展示严重级别、所属维度、问题摘要和修改建议。

## 评估维度

当前结果通常包含：

- **目的适配性**：目标、适用场景和边界是否清楚。
- **结构规范性**：文件组织和 Skill 结构是否符合要求。
- **指令适配性**：执行指令是否明确，是否与任务风险和自由度匹配。
- **内容一致性**：术语、步骤、脚本和参考资料是否互相一致。
- **工程健壮性**：失败处理、校验、依赖和可运行性是否充分。
- **安全风险性**：权限、破坏性操作、敏感数据和人工确认要求是否合理。

维度分用于定位薄弱方向；发布门禁主要关注高风险问题，而不是简单要求所有维度满分。

## 运行评估

1. 在工作台顶部选择目标 Skill 和版本。
2. 打开 **Skill 评估**。
3. 确认页面标记的是正式版本还是未发布快照。
4. 点击 **开始评估**；已有结果时点击 **重新评估**。
5. 等待系统完成文件读取、结构与边界检查、流程与安全检查以及证据汇总。
6. 查看质量门禁、维度分数和问题列表。

评估针对启动时的固定快照。文件在评估后发生变化时，状态会变为 **需要重新评估**，旧结果不能继续作为发布依据。

## 质量门禁状态

| 状态 | 含义 | 建议动作 |
| --- | --- | --- |
| **尚未评估** | 当前版本没有可用结果 | 开始评估 |
| **评估中** | 正在检查固定快照 | 等待完成 |
| **质量门禁通过** | 未发现阻断发布的高风险问题 | 继续实验或发布 |
| **质量门禁未通过** | 仍有高风险问题 | 查看问题并启动 AI 修复 |
| **需要重新评估** | 文件已变化，结果过期 | 对最新快照重新评估 |
| **评估失败** | 评估任务未正常完成 | 查看错误并重试 |

## AI 修复问题

当门禁未通过且存在高风险问题时：

1. 点击 **AI 修复 N 个高风险问题**。
2. 工作台左侧进入优化会话。
3. Copilot 归并问题并生成候选版本。
4. 候选自动执行新的静态质量评估。
5. 在 **优化记录**查看文件差异与阻断问题。
6. 门禁通过后，人工决定发布或放弃。

修复结果不会自动发布。若优化仍未通过，可在优化记录中继续修复。

## 如何阅读问题清单

每条问题通常包含：

- **严重级别**：例如 high、medium、low。
- **维度**：问题所属的质量方向。
- **摘要**：具体缺陷。
- **修改建议**：建议调整的文件、步骤或约束。

处理顺序建议：

1. 先解决 high 问题，恢复发布资格。
2. 再处理会影响触发和真实执行的 medium 问题。
3. 最后整理低风险表达和维护性问题。

> **Note**
> 静态质量评估不提供任务成功率、触发准确率或 A/B 收益结论。通过门禁后，仍应使用 Skill 实验验证真实效果。
