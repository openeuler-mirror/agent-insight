# 内置示例走查的成本参考

[内置示例端到端走查](/user-guide/example-walkthrough) 会带你用内置示例把核心闭环跑一遍。本页
给出在 **deepseek-v4-flash** 模型下走完 **Skill 生成 → 评测 → Skill 优化** 三个阶段的实测花费，
方便你预估开销。

> **Note**
> 成本会随所选模型单价、用例条数、评估器数量而浮动。下面的数字是用内置示例（约 10–18 条用例
> 规模）实测的一次结果，仅供量级参考，不是固定价。

---

## 一次完整闭环 ≈ 3.5–4 元

在 **deepseek-v4-flash** 下，完整走一遍 **Skill 生成 → 评测（含静态分析、触发分析、A/B 测试）
→ Skill 优化** 三个阶段，**单次实际花费大约 3.5–4 元**。

---

## 各阶段花费占比

| 阶段 | 实测花费 | 占比 |
| --- | ---: | ---: |
| Skill 生成 | 0.16 | ~5% |
| 静态分析 | <0.01 | ~0% |
| 触发分析（用例生成 + 运行） | 0.13 | ~4% |
| A/B 测试 — 执行 | 0.92 | ~27% |
| A/B 测试 — 评估 | 1.89 | ~56% |
| Skill 优化 | 0.25 | ~7% |
| **合计** | **约 3.4** | 100% |

> 表内为一次实测的逐阶段花费（合计约 3.4 元）。计入用例数与模型波动，单次预估按 **3.5–4 元**
> 取值更稳妥。

---

## 测量条件

- **模型**：deepseek-v4-flash
- **示例**：内置示例端到端走查（见 [example-walkthrough](/user-guide/example-walkthrough)）
