## 报告 Bug

## 提出新功能
建议先在 GitHub Discussions 讨论后再提 Issue。

## 提交代码
1. Fork 仓库
2. 创建分支：`git checkout -b feat/your-feature`
3. 提交：`git commit -m "feat(scope): your message"`
4. 推送：`git push origin feat/your-feature`
5. 提 PR

## 提交信息规范
本项目遵循 [Conventional Commits](https://www.conventionalcommits.org/)：
- `feat`: 新功能
- `fix`: 修复
- `docs`: 文档
- `refactor`: 重构
- `test`: 测试
- `chore`: 杂项

## Pull Request 流程
- 所有 PR 必须关联 Issue
- 必须通过 CI
- 必须有至少一位 Maintainer 审核通过
