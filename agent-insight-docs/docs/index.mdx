# Agent Insight Overview

Agent Insight 是一个开源的 Agent 全生命周期工程平台。它把 **运行观测**、**评测中心** 和 **Skills 能力管理** 整合到同一工作台，让团队能在一处完成 Agent 的开发、调试、评测、优化与上线。

与 Langfuse / LangSmith 不同，Agent Insight 把 **Skills（Agent 能力）** 作为一等公民，提供从生成、A/B 测试到优化的完整闭环。

## 平台能力一览

### 🔭 Observability（运行观测）
- 完整的 Trace / Span 链路记录
- 多轮对话 Session 与 User 归组
- ★ 智能诊断 — 主动发现失败模式
- ★ 质量监控 — 关键指标告警

### 🧪 Evaluation（评测中心）
- 评测数据集管理
- 评估器：LLM-as-Judge / 人工标注 / 自定义
- 离线批量评测 + 在线生产评测
- 多次实验得分对比

### 🛠️ Skills（核心差异化）
- **生成** — 用 AI 辅助产出 Skill 初稿
- **管理** — 版本化、Schema、状态流转
- **分析** — ★ 三步法 A/B 测试工作流
- **优化** — 基于评测数据自动迭代

### ⚙️ Platform（平台基础）
- Agent 管理与 Workspace 概览
- 模型注册、联网搜索、安装指导

## Why Agent Insight?

- **开源** · Apache 2.0，完全自托管
- **生产优化** · 异步上报零额外延迟
- **多语言 SDK** · Python / TypeScript 原生支持
- **框架覆盖** · LangChain、LangGraph、LlamaIndex、OpenAI Agents SDK 等 50+ 集成
- **OpenTelemetry 兼容** · 不绑死生态
- **Skills 闭环** · 业界独有的 Skills 全生命周期管理
