# TypeScript SDK

## 是什么

Agent Insight 的 TypeScript 官方 SDK（同时支持 JavaScript），与 [Python SDK](./python) 功能对等：

- **`observe()` 高阶函数** —— 包装异步函数，自动建调用树
- **显式 API** —— `AgentInsight.init / .logEvent / .flush`

支持 Node.js + Edge runtime（Vercel / Cloudflare Workers / Deno）。

## 安装

```bash
npm install @agent-insight/sdk
# 或
pnpm add @agent-insight/sdk
# 或
yarn add @agent-insight/sdk
```

最低 Node.js 版本：18+。也支持 Bun / Deno（ESM-only 兼容）。

## 怎么用

### 最小可运行

```typescript
import { AgentInsight, observe } from "@agent-insight/sdk";
import Anthropic from "@anthropic-ai/sdk";

AgentInsight.init({ apiKey: "ai_xxx", host: "http://localhost:3000" });

const anthropic = new Anthropic();

const myAgent = observe(async (query: string) => {
  const msg = await anthropic.messages.create({
    model: "claude-sonnet-4",
    messages: [{ role: "user", content: query }],
  });
  return msg.content[0].text;
});

await myAgent("hello");
```

### 嵌套调用自动建树

```typescript
const subAgentA = observe(async (q: string) => { /* ... */ });
const subAgentB = observe(async (q: string) => { /* ... */ });

const mainAgent = observe(async (query: string) => {
  const intermediate = await subAgentA(query);
  const final = await subAgentB(intermediate);
  return final;
});

await mainAgent("hello");  // 自动 3 层调用树
```

### 自定义 metadata

```typescript
const myAgent = observe(
  async (query: string, userId: string) => {
    AgentInsight.setUser(userId);
    AgentInsight.addTags(["region:cn", "tier:enterprise"]);
    AgentInsight.setLabel("customer-support");
    return answer;
  },
  {
    name: "customer-support-agent",
    metadata: { experiment: "exp-q1" },
  }
);
```

### 手动 log event

```typescript
const taskId = await AgentInsight.startSession({
  query: "hello",
  user: "u_xxx",
});

const result = await runMyAgent("hello");

await AgentInsight.logEvent({
  role: "tool",
  toolName: "bash",
  input: "lscpu",
  output: "...",
  durationMs: 120,
});

await AgentInsight.endSession({ answer: result });
```

### Next.js / Edge runtime

```typescript
// app/api/agent/route.ts
import { AgentInsight, observe } from "@agent-insight/sdk";

AgentInsight.init({
  apiKey: process.env.AGENT_INSIGHT_API_KEY!,
  host: process.env.AGENT_INSIGHT_HOST!,
});

export const POST = observe(async (req: Request) => {
  const { query } = await req.json();
  const answer = await runAgent(query);
  return Response.json({ answer });
});
```

### 优雅退出

```typescript
process.on("SIGTERM", async () => {
  await AgentInsight.flush({ timeoutMs: 5000 });
  process.exit(0);
});
```

## 关键 API

### `AgentInsight.init(options)`

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `apiKey` | string | — | 平台 API Key |
| `host` | string | `http://localhost:3000` | 平台地址 |
| `taskId` | string | auto | 显式 trace ID |
| `defaultMetadata` | object | `{}` | 每条 Trace 都带 |
| `queueSize` | number | 1000 | 队列容量 |
| `flushIntervalMs` | number | 5000 | 批量发送间隔 |
| `samplingRate` | number | 1.0 | 采样率 |
| `piiMasker` | PIIMasker | — | 脱敏配置 |
| `disabled` | boolean | false | 完全禁用上报 |

### `observe(fn, options?)`

```typescript
function observe<Args, R>(
  fn: (...args: Args) => Promise<R>,
  options?: {
    name?: string;
    metadata?: Record<string, unknown>;
    captureInput?: boolean;
    captureOutput?: boolean;
  }
): (...args: Args) => Promise<R>;
```

### 运行时 API

| 方法 | 用途 |
|---|---|
| `AgentInsight.setUser(userId)` | 设置终端用户 |
| `AgentInsight.setLabel(label)` | 主标签 |
| `AgentInsight.addTags(tags)` | 加 tags |
| `AgentInsight.attachFile(path, opts)` | 挂附件 |
| `AgentInsight.logEvent(event)` | 手动 log |
| `AgentInsight.flush({timeoutMs})` | 主动 flush |
| `AgentInsight.getTaskStats(taskId)` | 查统计 |

## 与主流 LLM SDK 的集成

### Anthropic

```typescript
import Anthropic from "@anthropic-ai/sdk";
const client = new Anthropic();

const agent = observe(async (q: string) => {
  const msg = await client.messages.create({
    model: "claude-sonnet-4",
    messages: [{ role: "user", content: q }],
  });
  return msg.content[0].text;
});
```

### OpenAI

```typescript
import OpenAI from "openai";
const client = new OpenAI();

const agent = observe(async (q: string) => {
  const resp = await client.chat.completions.create({
    model: "gpt-4o",
    messages: [{ role: "user", content: q }],
  });
  return resp.choices[0].message.content;
});
```

### LangChain

```typescript
import { ChatAnthropic } from "@langchain/anthropic";
const llm = new ChatAnthropic({ model: "claude-sonnet-4" });

const agent = observe(async (q: string) => {
  const resp = await llm.invoke(q);
  return resp.content as string;
});
```

详见 [Integrations · LangChain](../../integrations/frameworks/langchain)。

## 最佳实践

- **顶层只 init 一次** —— 不要在每个 request handler 里调
- **Edge runtime 关闭批量** —— Cloudflare Workers 没有持久 process，调高 `flushIntervalMs=0` 立即同步发
- **生产配 `defaultMetadata`** —— `{ environment: process.env.APP_ENV }`
- **server actions / API routes 都用 observe 包** —— 自动覆盖
- **不要在 client side 直接用 SDK** —— API Key 不能暴露给浏览器，由后端代理

## 常见问题

<details>
<summary>能在浏览器里用吗？</summary>

技术上能（SDK ESM 兼容），但**强烈不建议** —— API Key 会暴露给所有访客。正确做法：浏览器 → 你的后端 → Agent Insight。
</details>

<details>
<summary>类型定义在哪？</summary>

SDK 自带 .d.ts。在 VS Code / WebStorm 自动补全。所有类型导出：

```typescript
import type {
  Interaction, Session, Execution,
  PIIMaskerOptions, ObserveOptions,
} from "@agent-insight/sdk";
```
</details>

<details>
<summary>Edge runtime 没 process.on('SIGTERM') 怎么 flush？</summary>

Cloudflare Workers 用 `ctx.waitUntil(AgentInsight.flush())`，Vercel Edge 用 `await AgentInsight.flush()` 在 response 返回前。详见 [Integrations · Edge Runtime](../../integrations/overview)。
</details>
