# Get Started · Observability

接入第一条 Trace 通常 5 分钟以内。Agent Insight 提供三种接入路径，选你最方便的一种。

## 前置条件

- [ ] Agent Insight 服务已启动（[Self-Hosting](../self-hosting/overview)）
- [ ] 已登录看板拿到 API Key（**平台配置 → 安装指导** 页可复制）

## 路径 A：用平台采集插件（推荐 OpenCode / Claude Code 用户）

在 Agent 主机上跑一行命令，脚本会按你选的框架装好对应采集插件：

```bash
curl -sSf "http://<your-host>:3000/api/ingest/setup" | bash
# Windows 用户改成 PowerShell：
#   iwr "http://<your-host>:3000/api/ingest/setup/auto?apiKey=ai_xxx" | iex
```

支持的运行时：

| Agent 框架 | 采集方式 | 文档 |
|---|---|---|
| OpenCode | 原生插件 | [opencode integration](../integrations/frameworks/openai-agents-sdk) |
| Claude Code | 日志旁路 | [claude-code integration](../integrations/ide/claude-code) |
| OpenClaw | 日志旁路 | — |

## 路径 B：用 Agent Insight 原生 SDK

```python
# Python
pip install agent-insight
```

```python
from agent_insight import AgentInsight, observe

AgentInsight.init(
    api_key="ai_xxx",
    host="http://localhost:3000",
)

@observe()
def my_agent(query: str) -> str:
    # 你的 Agent 逻辑
    return answer

my_agent("hello")
```

```typescript
// TypeScript
import { AgentInsight, observe } from "@agent-insight/sdk";

AgentInsight.init({
  apiKey: "ai_xxx",
  host: "http://localhost:3000",
});

const myAgent = observe(async (query: string) => {
  return answer;
});

await myAgent("hello");
```

详见 [SDK · Python](./sdk/python) / [SDK · TypeScript](./sdk/typescript)。

## 路径 C：用 OpenTelemetry

已经在用 OTel 的项目直接把 exporter 指到平台即可：

```bash
export OTEL_EXPORTER_OTLP_ENDPOINT="http://localhost:3000/api/ingest/otel"
export OTEL_EXPORTER_OTLP_HEADERS="x-witty-api-key=ai_xxx"
```

平台兼容 OTel GenAI 语义约定。详见 [OpenTelemetry SDK](./sdk/opentelemetry)。

## 在 UI 中查看

打开看板的 **链路观测** 页面：

- 顶部 4 张指标卡（执行总数 / 成功率 / 平均耗时 / 平均 token）
- 中间一张执行记录表（按时间倒序、可按 user / framework / skill 筛选）
- 点击任一行 → 右侧 Drawer 显示多 Agent 调用树
