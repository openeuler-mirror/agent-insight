# Ask AI

Agent Insight 的文档支持 AI 问答。当你不确定某个功能在哪一页、或者想让一个 SDK 示例针对你的场景定制时，直接用自然语言提问比逐页翻更快。

## 三种使用方式

### 1. 文档站内的 Ask AI 按钮

每一页右上角都有 **Ask AI** 浮窗，点开后输入问题。它已经把当前页面的内容预置进了上下文，所以可以直接说"把这个示例改成 LangGraph 版本"。

<!-- TODO 截图：文档站任意页面右上角 Ask AI 浮窗展开后的样子。 -->

### 2. `.md` 端点（喂给你的 LLM）

每个文档页面都自带一个 `.md` 后缀的纯 Markdown 端点，可以直接喂给 ChatGPT / Claude / Cursor：

```
https://docs.agent-insight.dev/skills/analysis/ab-testing.md
```

把这个 URL 贴给 LLM，它会以这页内容为上下文回答你。

### 3. `llms.txt` 索引（一次性给 LLM 整套文档目录）

仓库根目录提供 [`llms.txt`](https://docs.agent-insight.dev/llms.txt)，里面是按章节分组的全量文档索引，符合 [llms.txt 规范](https://llmstxt.org/)。

```
curl https://docs.agent-insight.dev/llms.txt
```

适合给 Coding Agent（Cursor / Claude Code）做项目级 ground 资料。
