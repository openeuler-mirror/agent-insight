# Setup Evaluation

本页让你在 10 分钟内：建一个评测数据集、配一个评估器、对一批历史 Trace 跑一次离线评测，并在 UI 中看到分数。

## 前置条件

- [ ] Agent Insight 服务已启动
- [ ] 至少有几条历史 Trace（没有的话先跑一遍 [Start Tracing](./start-tracing)）
- [ ] **已在「模型注册」里配好至少一个评测用 LLM**（评估器要调用它做 LLM-as-Judge）

## 步骤一：创建评测集

进入 **评测中心 → 评测集 → 新建**，填三件事：

| 字段 | 含义 | 示例 |
|---|---|---|
| `name` | 集合名，命名建议带版本号 | `customer-support-v1` |
| `targetSkill` | 这个数据集服务于哪个 Skill（可选，留空 = 通用 agent 评测） | `pdf-extractor` |
| `datasetKind` | `ideal_output`（结果评测）或 `trajectory`（轨迹评测） | `ideal_output` |

接着进入「数据项录入」页，按 `{query, standardAnswer, keyActions[], rootCauses[]}` 的结构维护用例。

## 步骤二：选评估器

「评估器 / 指标」页面提供三种内置评估器，选一个：

- **LLM-as-Judge**：用 LLM 打分 + 给 judgment_reason
- **Trajectory Evaluator**：评估轨迹偏离 + 关键动作覆盖
- **自定义评估器**：自己写 JS 函数

参考 [Evaluation Methods](../evaluation/evaluation-methods/llm-as-a-judge)。

## 步骤三：跑一次评测

在 **评测任务** 页面新建任务：选评测集 + 选评估器 + 选要打分的 Trace 范围（按时间 / 按 Skill 名筛选），点 **Run**。

```bash
# 也可以直接调 API
curl -X POST http://localhost:3000/api/eval/rejudge \
  -H "Content-Type: application/json" \
  -H "x-witty-api-key: $API_KEY" \
  -d '{"task_id": "exec_xxx", "currentUser": "demo@163.com"}'
```

## 步骤四：查看分数

回到 **链路观测** 页面或 **评测中心**，每条被评的 Execution 行会多出 `answerScore` / `failures[]` 等字段。点击行打开右侧 Drawer，能看到逐条评分项与 `judgment_reason`。
