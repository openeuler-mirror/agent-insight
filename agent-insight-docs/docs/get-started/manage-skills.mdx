# Manage Skills

Skill 是 Agent Insight 的一等公民资产。本页让你在 10 分钟内：用 AI 生成一个 Skill 初稿、发布 v1、做一次静态合规检查。

## 前置条件

- [ ] Agent Insight 服务已启动
- [ ] 已在「模型注册」配好至少一个 LLM（Skill 生成 / 优化都要调它）

## 步骤一：生成一个 Skill

进入 **Skills 生成**，提交需求描述。例如：

> 创建一个 Skill，当用户请求查看系统信息时，自动执行 shell 脚本收集当前系统的关键信息（操作系统、CPU、内存、磁盘、网络等），以 Markdown 报告呈现给用户。

平台会基于模板调用 LLM 产出 `SKILL.md` 草稿 + 触发条件 + 关键行动列表。

<!-- TODO 截图：复用 agent-insight/docs/images/skill-gen.png — Skill 生成对话框 -->

## 步骤二：保存并发布为 v1

点击 **保存并发布**，平台会在 `Skill / SkillVersion` 两张表分别建一行，version=1 自动激活。

> 路径：`/api/skills` POST + `/api/skills/[id]/versions` POST，详见 [API Reference](../api-and-data-platform/endpoints/README)。

## 步骤三：跑一次静态合规检查

进入 **Skills 分析**，选刚生成的 Skill，点 **静态合规 → 重新扫描**。后台会跑一组规则引擎 + LLM 5D 评估，输出 `SkillIssue[]`（按严重度 high/medium/low 分类）。

<!-- TODO 截图：复用 agent-insight/docs/images/skill-analyse-static.png — 静态合规扫描结果 -->

每条 Issue 携带 `summary / evidence / suggestedFix`，可直接驱动下一步优化。

## 步骤四：把 Skill 推送到 Agent 主机

每个 Skill 版本都可以一键下载 ZIP（含 `SKILL.md` + `scripts/`）或通过 Sync API 直接推到 Agent 主机的 `~/.opencode/skills/<name>/`：

```bash
curl -X POST http://localhost:3000/api/ingest/sync/opencode \
  -H "x-witty-api-key: $API_KEY" \
  -d '{"skillId": "skill_xxx", "version": 1, "user": "demo@163.com"}'
```

之后 Agent 调用时就能加载到这个 Skill。
