# Get Started · Evaluation

本页让你：建评测集 → 跑评估 → 看分数。10 分钟以内完成。

## 前置条件

- [ ] Agent Insight 服务已启动
- [ ] 已有至少几条历史 Trace（没有的话先看 [Start Tracing](../get-started/start-tracing)）
- [ ] **已在「模型注册」配好至少一个 LLM**（评估器要调用它）

## 步骤一：创建评测集

进入 **评测中心 → 评测集 → 新建**，最少填三个字段：

```json
{
  "name": "customer-support-v1",
  "datasetKind": "ideal_output",
  "targetSkill": "pdf-extractor"
}
```

| 字段 | 取值 | 何时用 |
|---|---|---|
| `datasetKind` | `ideal_output` | 评测最终输出（结果导向） |
| `datasetKind` | `trajectory` | 评测调用轨迹（过程导向） |
| `targetSkill` | Skill name | 数据集挂在某个 Skill 上 |
| `targetSkill` | 留空 | 通用 Agent 评测 |

然后进入「数据项录入」页，每条 case 至少填 `query` + `standardAnswer`，可选 `keyActions[]` / `rootCauses[]`。

```bash
# 也可以用 API 批量导入
curl -X POST http://localhost:3000/api/agent-datasets \
  -H "x-witty-api-key: $API_KEY" \
  -d '{
    "user": "demo@163.com",
    "name": "customer-support-v1",
    "datasetKind": "ideal_output",
    "cases": [
      {"query": "退款流程", "standardAnswer": "...", "keyActions": ["..."]}
    ]
  }'
```

## 步骤二：选评估器

进入 **评估器 / 指标** 页面。内置三种：

| 评估器 | 适用 |
|---|---|
| **LLM-as-Judge** | 通用开放问题，按 `standardAnswer` 对比 |
| **Trajectory Evaluator** | 看 Agent 走的步骤是否覆盖 `keyActions` |
| **Routing Evaluator** | 看 Agent 是否选对了 Skill（路由意图评测） |

也可以自定义。详见 [Custom Evaluators](./evaluation-methods/custom-evaluators)。

## 步骤三：跑评测任务

在 **评测任务** 页面新建任务，选三件事：

- **评估对象**：哪批 Trace（按时间 / 按 Skill / 按 user 筛选）
- **评测集**：用哪个数据集
- **评估器**：用哪个评估器

点 **Run**，任务后台异步跑。每条 Trace 完成评测后写入 `Evaluation` 表，前端实时刷新。

```bash
# 也可以一条一条重评
curl -X POST http://localhost:3000/api/eval/rejudge \
  -H "x-witty-api-key: $API_KEY" \
  -d '{"task_id": "exec_xxx", "currentUser": "demo@163.com"}'
```

## 步骤四：在 UI 中查看

回到 **链路观测** 列表，被评过的行会多出 `answerScore` / `failures[]`。点击行打开右侧 Drawer，能看到：

- 总分 + 每个评分项细分
- LLM-as-Judge 的 `judgment_reason`
- 关键动作覆盖情况
- 失败用例归因
