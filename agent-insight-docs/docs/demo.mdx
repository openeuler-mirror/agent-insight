# Live Demo

Agent Insight 提供一个公网 Demo 环境，你不用本地部署就能体验完整功能 —— Trace 浏览、Skill 编辑、A/B 评测、智能诊断都开放了只读 + 受控写入。

> 在线 Demo：<https://demo.agent-insight.dev>（如未上线请改用本地 Docker 启动方式）

## 你可以做什么

| 体验内容 | 入口 | 大约耗时 |
|---|---|---|
| 浏览一条多 Agent 调用 Trace | 左侧栏「链路观测」 → 任选一行 | 1 分钟 |
| 看一次 A/B 测试三步法报告 | 「Skill 分析」 → 「A/B 测试」 → 历史任务 | 2 分钟 |
| 查看 Skill 的优化点列表 | 「Skill 优化」 → 任选一个 Skill | 2 分钟 |
| 跑一次评测数据集 | 「评测中心」 → 选择数据集 → Run | 3 分钟 |

## Demo 环境的限制

- **数据每 24 小时重置一次**，不要把它当生产环境用
- **不开放真实 LLM Key**：评测/优化使用平台内置的演示模型
- **写操作有速率限制**：每个 IP 每分钟最多 30 次 POST 请求

## 想跑自己的实例？

参考 [Self-Hosting Overview](./self-hosting/overview)，单机 Docker Compose 5 分钟可起。
